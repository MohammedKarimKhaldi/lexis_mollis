# Spécifications historiques

Les fichiers `EPIC_A` à `EPIC_I` ont guidé la construction initiale de Lexis Mollis. Ils sont
conservés pour expliquer les décisions, contrats et critères d'acceptation d'origine, mais leurs
compteurs, calendriers et états d'avancement ne décrivent plus nécessairement le dépôt actuel.

Pour l'état et les priorités en vigueur, utiliser :

- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) pour le flux technique et les frontières ;
- [`../PROJECT_STATUS.md`](../PROJECT_STATUS.md) pour les compteurs vérifiés ;
- [`../ROADMAP.md`](../ROADMAP.md) pour les travaux restants.

Les invariants de fidélité OCR, provenance, droits et déterminisme restent applicables.
